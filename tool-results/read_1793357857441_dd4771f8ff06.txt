   275→   275→## Known issues / gotchas
   276→   276→
   277→   277→- **M7 — calling dynamic route handlers directly in tests**: the handler signature is
   278→   278→  `(req, ctx)` where `ctx.params` is a Promise. Passing the cookie as the 2nd arg (instead
   279→   279→  of into the Request headers) silently yields 401 (the request lacks the cookie). Use
   280→   280→  `handler(jsonReq(url, body, cookie), { params: Promise.resolve({ id }) })`.
   281→   281→- **M7 — planting a node with error-tracking history keeps `learning`**: `approveSeed`
   282→   282→  uses upsert `update:{}` on purpose (§B5 never overwrites practiced state). Only the
   283→   283→  skills WITHOUT history get a fresh `available` state. Tests + UI must not expect a node
   284→   284→  that already produced confident errors to flip to `available`.
   285→   285→- **M7 — user-generated GraphNodes are NOT FK-owned by users**: `ownerId` is a soft
   286→   286→  reference; deleting a user does not delete their created nodes (by design — nodes feed
   287→   287→  the shared world later). Test teardowns must delete them explicitly. The idempotency
   288→   288→  test's mirror invariant is world-scoped (`isUserGenerated:false`) for the same reason.
   289→   289→- **M6 — stale Prisma client after `prisma db push`**: a RUNNING dev server keeps the old
   290→   290→  generated client in its require cache → new schema fields (e.g. NodePosition.pinned)
   291→   291→  cause `Unknown argument` 500s even though tests (fresh processes) pass. Fix: restart the
   292→   292→  dev server via `setsid bash .zscripts/dev.sh > /tmp/devsh.log 2>&1 < /dev/null & disown`
   293→   293→  (the harness's own entry: bun install → db:push → bun run dev → disown). Plain `nohup bun
   294→   294→  run dev &` does NOT survive between tool calls. Check `dev.log` + `curl :3000` after.
   295→   295→- **M6 — SVG height trap**: `h-full` on an `<svg>` inside a flex-grown div resolves to the
   296→   296→  150px replaced-element default (percentage against an indefinite height). The tree canvas
   297→   297→  svg must stay `absolute inset-0` inside the `relative overflow-hidden` canvas div.
   298→   298→- **M6 — panel vs. canvas pointer handlers**: the panel lives inside the pointer-drag
   299→   299→  container; `onPointerDown` must ignore events from `[data-testid=node-panel]` and
   300→   300→  background-deselect must be skipped when the press started on a node — otherwise panel
   301→   301→  buttons unmount before their onClick fires.
   302→   302→- **M6 — node ids contain colons** (`en:word:flight`) — never `split(':')` on composite
   303→   303→  "id:value" fingerprints; use `lastIndexOf(':')`.
   304→   304→- **M6 — availability map key**: `computeAvailability` returns `{ node: EngineNode, ... }`
   305→   305→  — the per-id map must key on `a.node.id` (TS won't catch `a.nodeId` under esbuild/vitest,
   306→   306→  which strip types without checking).
